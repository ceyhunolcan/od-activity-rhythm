# Variable dictionary for `analytic_full.csv`

Generated by `stage1_build_analytic.py`. n = 2,327 participants after
inclusion criteria (PST done, no acute URI, not pregnant, >= 4 valid
accelerometer days).

## ID and design

| variable | type | description |
|----------|------|-------------|
| SEQN | int | NHANES respondent identifier |
| WTMEC2YR | float | MEC 2-year sample weight |
| SDMVSTRA | int | masked variance stratum |
| SDMVPSU | int | masked variance PSU |

## Demographics

| variable | type | description |
|----------|------|-------------|
| age | int | age at exam, years |
| female | 0/1 | 1 if female |
| race_eth | int | NHANES RIDRETH3 code (1=MexAm, 2=OtherHisp, 3=NHW, 4=NHB, 6=NHA, 7=Other) |
| education | int | NHANES DMDEDUC2 (1=<9th, 2=9-11, 3=HS, 4=SomeColl, 5=College+) |
| pir | float | family income-to-poverty ratio |

## Exposure (olfactory)

| variable | type | description |
|----------|------|-------------|
| PST_correct | int 0..8 | # odors correctly identified on 8-item PST |
| od_binary | 0/1 | 1 if PST_correct <= 5 (NHANES standard cutoff) |
| CSQ240 | 1/2 | self-reported smell problem (1=Yes, 2=No) |

## Accelerometer (primary outcomes)

| variable | type | description |
|----------|------|-------------|
| mean_mims | float | per-day mean MIMS, averaged across valid wake hours |
| mvpa_min | float | min/day in MVPA (>= 37.5 MIMS/min, Karas cut-point) |
| sedentary_min | float | min/day sedentary (< 10.558 MIMS/min) |
| light_min | float | min/day in light intensity |
| IS | float | interdaily stability (Witting et al.) |
| IV | float | intradaily variability |
| RA | float | relative amplitude (M10 - L5) / (M10 + L5) |
| M10 | float | most-active 10-hour average MIMS |
| L5 | float | least-active 5-hour average MIMS |
| ASTP | float | per-person active-to-sedentary transition probability |
